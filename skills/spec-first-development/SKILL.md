# 规格先行开发

输出足够指导实现的轻量规格：问题、用户价值、范围、非范围、现状、方案、数据或接口变化、失败路径、验收标准和验证方法。

区分已经确认的事实、合理假设和待决定问题。只有会显著改变方案的问题才阻塞实施；其余采用可逆默认值并明确记录。

任务拆分采用可独立验证的纵向切片，避免只按“前端、后端、测试”拆成无法单独交付的层。
