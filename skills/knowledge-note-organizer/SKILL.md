# 知识笔记整理

先识别用户现有笔记工具、目录和命名习惯。保留来源与原始含义，区分事实、推论、问题和行动项。

整理结果包含：清晰标题、简短摘要、主题正文、来源、相关概念、待确认问题和必要标签。优先链接已有笔记，避免为每个句子创建碎片文件。

批量移动、重命名或删除文件前先展示映射并取得确认。若目标是思源、Obsidian 或其他特定工具，遵循其链接与元数据格式。
