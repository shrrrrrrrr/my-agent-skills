# 中文写作规范

根据读者、目的和发布渠道选择语气。优先使用清楚、具体、自然的现代汉语，避免空泛口号、翻译腔、无意义排比和过度术语。

中文与英文或数字之间保持一致的空格规则，使用全角中文标点。段落围绕一个中心推进，标题准确表达内容，不用夸张承诺吸引点击。

修改时依次检查事实、结构、段落、句子和排版。保留作者有意义的个人语气，不把所有文本改成同一种模板。
